# Movie Z

Movie Z бол үзэх киногоо сонгож, хаана үзэхээ олоход туслах сайт юм. Киноны мэдээлэл болон Монголын кино театруудын байршлыг нэг дороос харах боломжтой.

[Сайтаар зочлох](https://movieweb-sandy.vercel.app)

Эндээс та:

- Өргөө, Тэнгис, Prime Cineplex-д гарч буй кинонуудыг харна.
- Киногоо нэр, төрлөөр нь хайж, тайлбар, үнэлгээ, үзэгчдийн сэтгэгдлийг уншина.
- Киноны нээлтийн огноо болон дэлгэрэнгүй хуудсанд ижил нэрээр олдсон Монгол дахь үзвэрийн мэдээллийг харна.
- Киноны трейлерийг үзнэ.
- Өөрт ойр кино театр, түүнд хүрэх чиглэлийг олно.
- Кино театрын албан ёсны сайт руу орж, үзвэрийн цаг болон тасалбараа шалгана.

Сайтыг гар утас, таблет, компьютер дээр ашиглаж болно. Бараан болон цайвар горимтой.

Киноны мэдээллийг TMDB, үзвэрийн мэдээллийг кино театруудын албан ёсны сайтаас авдаг. Тасалбарын худалдан авалт тухайн кино театрын сайтаар хийгдэнэ.

TMDB-ийн нээлтийн огноо, Монголын кино театрын нээлтийн огноо ялгаатай байж болно. TMDB-д мэдээлэл нь байвал Монгол дахь хамгийн сүүлийн кино театрын нээлтийг харуулна. Кино театруудын өөрсдийн нийтэлсэн нээлтийн огноог мөн тусад нь үзүүлнэ. Өнөөдрийн жагсаалт нь өмнөх бүх үзвэрийн архив биш тул захиалахаасаа өмнө киноны нэр, хувилбар, цагийг албан ёсны сайтаас шалгаарай.

This product uses the TMDB API but is not endorsed or certified by TMDB.

## Ашигласан технологиуд

- **Next.js 16 (App Router)** — хуудасны чиглүүлэлт болон серверээс киноны мэдээлэл авах API.
- **React 19** — хайлт, шүүлтүүр болон бусад интерактив хэсгүүд.
- **TypeScript** — кодын төрлийг шалгаж, алдаа багасгах.
- **Tailwind CSS 4, CSS animations** — загвар, өнгө, хөдөлгөөнт дэвсгэр болон зураг дээр хулгана очиход томрох эффект.
- **HeroUI 3** — товч, карт, таб, шүүлтүүр, хуудаслалт зэрэг интерфэйсийн бүрдлүүд.
- **React Aria** — гарын товчоор удирдах боломж болон хуудас хоорондын шилжилтийн холболт.
- **Lucide React** — дүрс тэмдэгтүүд.
- **Manrope** — кирилл үсэг дэмждэг үндсэн фонт.
- **Embla Carousel, Wheel Gestures** — киноны постеруудыг хулгана, мэдрэгчтэй самбар, хуруугаар гулсуулж үзэх.
- **Leaflet, OpenStreetMap** — кино театруудыг газрын зураг дээр харуулах. Ойр кино театрыг олоход хөтчийн байршил тодорхойлох боломжийг ашиглана.
- **TMDB API** — киноны мэдээлэл, үнэлгээ, сэтгэгдэл, трейлерийн холбоос.
- **Cheerio** — кино театруудын сайтаас нийтэд нээлттэй киноны жагсаалтыг унших.
- **next-themes** — бараан, цайвар горимыг удирдах.
- **Node.js-ийн тестийн хэрэгсэл** — киноны жагсаалт, сэтгэгдлийг боловсруулах логикийг шалгах.
- **Vercel** — сайтыг интернэтэд байршуулж ажиллуулах.
